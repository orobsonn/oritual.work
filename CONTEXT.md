# Glossário

| Termo | Significado |
| --- | --- |
| Ritual | A rotina da pessoa ao abrir o app de manhã para planejar o dia com intenção. É o conceito central do produto |
| Diário (entrada do dia) | O registro de um dia: gratidão e intenção de manhã; coisas incríveis, o que podia ter feito e planos de amanhã à noite |
| Tarefa | Item do dia, de categoria Trabalho ou Pessoal. Não concluída é "esquecida": não passa para o dia seguinte |
| Tarefa agendada | Tarefa com data (e hora opcional) futura; pode virar evento no Google Calendar |
| Hábito | Prática recorrente, semanal (dias definidos) ou mensal (só uma frequência, aparece como lembrete) |
| Meta | Objetivo de progresso com valor-alvo (ex.: ler 12 livros), com histórico de avanços |
| Afirmação | Frase motivacional definida uma vez nas configurações e exibida no ritual matinal |
| Casal | Vínculo entre duas contas, feito por código de convite, para compartilhar metas e hábitos. O diário pessoal nunca é compartilhado |
| Convite | Código com validade que uma pessoa gera para vincular o parceiro(a) |
| Premium | Compra única (R$ 47) que libera metas e hábitos de casal |
| Onboarding | Configuração inicial feita no primeiro acesso |
